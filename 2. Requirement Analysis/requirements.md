# 2. Requirement Analysis

## Project Title
EduGenie: Google Gemini Powered Learning Assistant

## Functional Requirements

1. The system should allow students to enter questions.
2. The system should provide AI-generated answers.
3. The system should explain difficult topics in simple language.
4. The system should summarize study materials.
5. The system should generate quiz questions.
6. The system should support exam preparation.

## Non-Functional Requirements

- The system should be easy to use.
- The response should be clear and understandable.
- The system should provide responses within a reasonable time.
- User input should be handled safely.
- The application should work on common web browsers.

## Hardware Requirements

- Smartphone or computer
- Internet connection

## Software Requirements

- Web browser
- Python
- Google Gemini API
- GitHub

## Target Users

- School students
- College students
- Students preparing for examinations
