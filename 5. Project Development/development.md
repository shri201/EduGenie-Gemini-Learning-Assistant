# 5. Project Development

## Project Title
EduGenie: Google Gemini Powered Learning Assistant

## Development Overview

EduGenie is developed as an AI-powered learning assistant for students.

## Technologies Used

- Google Gemini AI
- HTML
- CSS
- JavaScript
- GitHub

## Main Features

### 1. Ask Questions
Students can ask questions about their subjects.

### 2. Simple Explanations
The system provides easy-to-understand explanations.

### 3. Summarization
Students can get short summaries of study materials.

### 4. Quiz Generation
The system can generate practice questions and quizzes.

### 5. Exam Preparation
Students can use the assistant for revision and exam preparation.

## Development Process

1. Design the user interface.
2. Connect the application with Gemini AI.
3. Process student questions.
4. Generate AI responses.
5. Display the responses to the student.
6. Test the features and fix errors.

## Expected Result

EduGenie will provide students with an easy and interactive AI-based learning assistant.
