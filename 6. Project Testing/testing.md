# 6. Project Testing

## Testing Objective

The EduGenie application is tested to make sure that its main features work correctly.

## Test Cases

### Test Case 1 – Ask a Question
Input: Student enters a study-related question.

Expected Result: EduGenie provides a clear answer.

### Test Case 2 – Simple Explanation
Input: Student asks for a simple explanation of a difficult topic.

Expected Result: The topic is explained in easy language.

### Test Case 3 – Summary
Input: Student provides study material.

Expected Result: EduGenie generates a short summary.

### Test Case 4 – Quiz Generation
Input: Student requests quiz questions.

Expected Result: EduGenie generates practice questions.

### Test Case 5 – Exam Preparation
Input: Student asks for important revision points.

Expected Result: EduGenie provides useful revision points.

## Testing Result

The planned features were checked to ensure that EduGenie can support students in learning, revision and exam preparation.
